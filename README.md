# ویترین محصولات شیرآلات و لوازم آشپزخانه

نسخه آماده اجرا روی Railway، با Flask + SQLite.

## امکانات
- ویترین مدرن و مینیمال، فارسی و RTL
- کاملاً واکنش‌گرا برای موبایل
- صفحه اختصاصی هر محصول و URL مناسب
- پنل مدیریت
- افزودن/ویرایش/حذف محصول
- آپلود تصویر محصول
- مدیریت دسته‌بندی‌ها توسط مدیر
- تنظیم نام فروشگاه، توضیح، تلفن و آدرس
- بدون سبد خرید و پرداخت؛ سفارش به‌صورت حضوری
- SQLite بدون نیاز به سرویس دیتابیس پولی

## اجرای محلی
```bash
pip install -r requirements.txt
python app.py
```
سپس `http://127.0.0.1:8080`

## ورود اولیه پنل
نام کاربری: `admin`
رمز عبور: `admin123`

حتماً در Railway این دو متغیر را تغییر دهید:
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`

و یک `SECRET_KEY` تصادفی تعیین کنید.

## Railway
Repository را به Railway متصل کنید. Railway با `railway.json` و Procfile برنامه را با Gunicorn اجرا می‌کند.

### نکته مهم درباره ذخیره‌سازی رایگان
SQLite و تصاویر در فایل‌سیستم محلی کانتینر ذخیره می‌شوند. در محیط‌هایی که فایل‌سیستم موقت دارند، با Redeploy/حذف Volume ممکن است اطلاعات از بین برود. برای نسخه تولیدی بهتر است بعداً یک Volume یا فضای فایل/تصویر دائمی اضافه شود.
